# Mawaqit — مواقيت الصلاة (Android releases)

Prayer times for Lebanon and anywhere else, calculated on-device with the Jafari method as in
Al Sirat's published tables, with the Hijri calendar of your marjaa (Khamenei / Sistani / Fadlallah),
notifications with the adhan, widgets and more.

**Download:** the APK attached to the [latest release](../../releases/latest). Install it over your
current version — it's signed the same way, so your settings are kept. The app checks this page
for new versions by itself (Settings → app version).
